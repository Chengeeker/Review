# Review 工程复盘

## 公开文档与技术记录

- 只检查 README 会漏掉开发说明、历史记录、配置中的产品介绍和其他公开材料。上传前统一检查正文、链接、文件名与提交说明。
- 内部技术记录独立保留，发布材料使用真实、中性的功能描述。保留运行必需的源码标识和接口，不用全文替换破坏功能。
- 本地完整技术记录只维护一个统一文档，直接更新对应章节，不拆分主题源目录或自动拼接。公开文档单独维护，不把完整内部技术资料直接同步回公开文档。

## 评论筛选与并发请求

- 重复选择当前筛选项仍须重置分页并读取第一页；请求代次隔离过期回包。
- 筛选模式与服务端 flow 参数分别处理；保持分批扫描、失败重试和完整回复遍历。

## 头像与列表身份

- 同一头像的不同尺寸 URL 是不同缓存键，打开缓存开关不足以避免重新加载。详情页同一作者沿用来源头像 URL，其他资料正常更新。
- 个人主页有独立的资料缓存与入口，须单独检查；仅复用同一用户已解码的头像，资料更新及慢/失败换图期间保留已有画面。保留旧帧的头像按用户ID设key，防止另一用户继承图片。
- 可变高度列表使用内容 ID 作为稳定 key，并提供最新索引映射，防止正文状态留在错误位置。

## 图片返回期间的点击区域

- 画廊自己的按钮回调安全，不代表系统返回安全。画廊逻辑pop后仍在退场，系统返回可能落到来源页并触发SystemNavigator退出。使用来源ModalRoute的临时PopEntry处理，预测式手势保持最初路由身份直至提交/取消，不能在手势中途重新选择当前页；绑定观察者退出需避开正在遍历的回调列表。
- 延迟单击回调必须验证来源路由仍为当前路由，不能只检查mounted。画廊pop后在动画退场期间仍挂载，旧回调调用Navigator.pop会误退主页或替代画廊。退场时取消点击计时器及指针记录，处理上一笔待定单击后再次确认路由身份；返回按钮也共用所属路由检查，不能只依赖UI禁用或canPop。
- Hero被反向接管时，外层动画会换成新路由，但已有shuttle可能继续复用。裁切不能一直读取shuttle建立时的旧animation；保存两端Hero尺寸，按当前绘制尺寸的主要变化轴求插值，仅尺寸相同时回退动画值。测试既要检查重开瞬间，也要检查中途和交接前的实际像素，覆盖多轮操作。
- Hero飞行时的来源占位不参与命中测试，外层卡片可能收到本应属于图片的点击。共享缩略图在Hero外保留原尺寸的opaque Listener即可保留来源手势，不增加绘制、手势识别器或全局重开回调。
- 共用打开入口仅在同一Navigator中的图库正在打开或已打开时阻止重复push；返回中及已退场待清理的实例允许来源重新打开，飞行仍交给原HeroController处理。
- 回归须使用真实Navigator、图片网格和可点击外层卡片，覆盖打开未完成即返回、返回结束前后松手和实际飞行像素连续性；不能仅检查路由属性或阻止卡片导航。

## 点击反馈与液态玻璃

- 去除水波纹时保留触感桥接，使用不绘制墨迹的反馈工厂；主题仅清除按压态覆盖，保留焦点和悬停回退。
- 局部显式墨迹工厂和带前景色的按钮样式可能覆盖主题，须一并检查。液态玻璃透镜属于独立交互，不随Material墨迹移除。
- 回归比较按下、长按前后的实际像素，并检查手势回调、触感开关和键盘焦点；构建通过不代表真机视觉验收。

## 设置标题与字号

- 分组标题应在卡片外，按内容实际起始边对齐；个性化和备份分组标题下12dp再接卡片。测试同时核对Card祖先、横向坐标与纵向间距，不能只测padding声明。
- 删除设置分隔线须覆盖子页面、展开项和关于弹窗；功能预览保留用户所选的内容样式。
- 全局默认字号95%同时作用于存储缺省值和主题初始值，保留用户已保存选择与系统缩放曲线。

## 工作区清理

- 只删除已确认可重建的产物；重复二进制须与保留副本逐项核对哈希。整个build不等同于缓存，回退包、源码恢复副本和复盘证据应保留。
- 清理前检查目标路径与目录链接，清理后检查保留文件哈希和Git差异。仅清理生成物不重建安装包，后续首次构建会重新生成缓存。

## 正文与附件

- 展开、收起入口紧跟相应正文，放在图片和视频前；转发内容独立控制。不能通过改变附件尺寸或滚动布局掩盖顺序问题。

## 画廊与共享图片转场

- 默认弧形矩形插值可能导致居中图片横移；共享图片两端统一使用线性矩形插值。
- 转场飞行层没有原分页器祖先，图片构建器不能强制解包分页状态。回归须走真实 Navigator push，而非只在主页挂载画廊。
- 保持分页视口和图片手势子树稳定；真实解码帧、快速拖动、反向惯性、缩放和返回均需覆盖。
- 不预加载全部原图和视频；快速滑动时延迟媒体激活，最终选中后再恢复。

## 安全备份与会话恢复

- 普通数据使用完整白名单；凭据仅在用户明确选择全量模式时包含。
- 原生会话不在普通偏好文件中，须单独导出可迁移字段；恢复前校验账号并重新加密，防止旧账号会话混入。
- 恢复不调用会清除原生会话的手工导入流程，不重新初始化曾导致冷启动问题的 Android CookieManager。
- 全量文件含明文凭据；后续安全备份不会清理服务器已有的敏感历史副本。

## 构建与验证

- Kotlin Android 插件不可因清理配置被移除，应用脚本同时依赖 Android 与 Kotlin DSL。
- PowerShell 中 Gradle 的 `-P` 参数整体加引号，避免点号等内容被拆解。
- 显式 ABI 过滤配合 `disable-abi-filtering=true`，避免工具链重新启用其他架构。
- 测试、构建和静态 APK 检查须分别记录；不能据此宣称真机帧率、播放、账号或云盘恢复通过。
