# Review

Review 是使用 Kotlin、Jetpack Compose 和 Material 3 构建的 Android 动态阅读应用。

- 信息流、分组、热搜、搜索、个人主页、评论与消息。
- 全屏画廊、实况照片、HDR、视频播放和媒体保存。
- 磨砂顶栏、悬浮底栏、主题、动态取色、字号和触感设置。
- 草稿、收藏、浏览记录与 WebDAV 备份。

Android 8.0 起支持，正式安装包为 ARM64，应用标识为 `com.review`。已安装旧版的用户可用同签名、较高版本代码的安装包覆盖升级。早期版本的部分登录和设置使用不同的存储格式，升级后可能需要重新登录或调整设置。
