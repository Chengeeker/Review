# Review

An Android reading app built with Kotlin, Jetpack Compose, and Material 3.

- Feeds, search, profiles, comments, and messages.
- Full-screen galleries, live photos, HDR images, and video playback.
- Themes, dynamic colors, font controls, and haptic feedback.
- Drafts, bookmarks, history, and WebDAV backup.

Android 8.0+ · ARM64

Upgrades require the same signing certificate and a higher version code. Older installations may need to sign in again or adjust settings.
